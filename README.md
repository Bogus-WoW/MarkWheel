# MarkWheel

Hold a key to open a wheel of raid markers at your cursor; release over a marker to put it on the mob you were hovering. Works in combat.

An addon for **World of Warcraft: Forever** (interface 16001), made for personal use and shared as-is.

## Install

- **WowUp:** Add Addon → Install from URL → paste this repository's URL. Updates come with each new release.
- **Manual:** download `MarkWheel-<version>.zip` from the Releases page and unzip it so the `MarkWheel` folder sits in `_forever_\Interface\AddOns\`.

Type `/reload` in game after updating.
